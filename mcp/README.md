# fRiENEMiES MCP

Tools exposed:
- `resolve_token(tokenId|owner|ens)` → character manifest stub
- `list_animation_packs(filters)` → pack registry
- `validate_asset(glbUrl)` → structured validation report
- `generate_template(target, manifestUrl)` → file list + setup instructions

## Run
```bash
cd mcp
npm install
npm run build
npm start
```
